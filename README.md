# Population simulation

Simulation de promeneurs en vue de dessus, réalisée avec [Three.js](https://threejs.org/).

Des personnages se baladent aléatoirement sur un terrain (place, fontaine, étang, bâtiments, arbres), évitent les obstacles et s'arrêtent de temps en temps.

- Molette / pincement : zoom
- Glisser : déplacer la vue
- Clic sur un personnage : afficher ses infos et le suivre

Site : https://frederic-bui-ai-assistant.github.io/population_simulation/
